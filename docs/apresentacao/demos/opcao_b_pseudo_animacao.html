Passo 2 de 4 · Cassandra

Cassandra prepara a contagem na escrita

A pergunta definiu o desenho de event_counts_by_day.

1. Evento entra

A API registra e ativa o evento. A transição aplicada dá direito a atualizar o agregado.

2. Contador recebe +1

Na célula do dia, hora, categoria e severidade. A exclusão concluída aplica −1.

3. CQL lê por data

Uma consulta por data UTC, em paralelo, com faixa de horas dentro de cada partição.

4. API devolve a série

Filtra categoria e severidade quando pedido e soma os contadores para o dashboard.

O hash da data gera o token que localiza a partição. Exemplo didático em 27/10: um alerta às 09h, severidade 3, soma 1 ao seu contador.

Passo 3 de 4 · PostgreSQL

PostgreSQL conta quando o painel consulta

A consulta medida parte de events, a tabela relacional com uma linha por evento.

1. API envia SQL

O dashboard pede o mesmo período e os mesmos filtros à outra fonte.

2. Índice delimita a faixa

events_time_cover_idx usa occurred_at e inclui categoria e severidade.

3. SQL agrupa e conta

Filtra pelo período e pelos critérios opcionais. Agrupa por hora, categoria e severidade e faz COUNT(*).

4. API devolve a série

Usa os totais do SQL para devolver ao dashboard o mesmo formato da outra fonte.

Cerca de 245 mil entradas de índice no recorte

O plano medido usou index-only scan. O índice fornece os campos necessários, e o banco ainda precisa agrupar e contar as entradas do intervalo.

Mesma resposta

Os 30 pares bateram. Com pré-agregação no PostgreSQL (E5), a leitura ficou na mesma ordem de grandeza, em fronteiras de medição diferentes. A view depende de refresh.

Quando usar Cassandra

Consultas previsíveis por chave, com potencial para volume e escrita intensa em cluster. Perguntas ad hoc e joins exigem outro desenho. O lab de um nó deixa a escala horizontal fora da medição.

Quando usar PostgreSQL

Joins, transações e análise flexível. No CyberGuard, venceu as buscas por ID, dispositivo, IP e alertas (E1–E3). Nas páginas, as projeções do Cassandra ainda exigem recuperar os eventos completos.
